# Finly — лендинг сервиса личных финансов

Демонстрационный лендинг для вымышленного сервиса управления личными финансами.
Проект для портфолио: акцент на UI/UX, адаптивную вёрстку, анимации и компонентную архитектуру.

## Стек

- **Next.js 16** (App Router, React Server Components)
- **TypeScript** (strict)
- **Tailwind CSS v4**
- **shadcn/ui** (`base-nova`, поверх `@base-ui/react`) — Accordion, Dialog, Sheet, Switch, Input, Badge, Button
- **lucide-react** — иконки
- **Framer Motion** — скролл-анимации, spring-счётчики, переходы

Backend отсутствует — все данные (`src/lib/data.ts`) статические, форма CTA имитирует сетевой запрос через `setTimeout`.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Продакшн-сборка и проверка типов:

```bash
npm run build
npm run lint
```

## Архитектура

```
src/
  app/                    layout.tsx (шрифты, SEO/OG-метаданные), page.tsx, globals.css (дизайн-токены)
  components/
    layout/               шапка, мобильное меню (Sheet), футер
    sections/              по одному файлу на секцию лендинга
    finly/                 переиспользуемые доменные блоки:
                            AnimatedCounter, SpendingChart (SVG, самостоятельно
                            "дорисовывается" при скролле), CtaDialog (форма с
                            валидацией/загрузкой/успехом), TransactionList
                            (фильтр по категориям + empty state), карточки
                            фич/тарифов/отзывов/шагов, Reveal-обёртки для
                            scroll-анимаций
    ui/                    примитивы shadcn/ui
  lib/
    data.ts                весь контент страницы (тексты, тарифы, транзакции)
    utils.ts                cn() + форматирование валюты/процентов
```

## Дизайн

Тёплый бумажный фон вместо белого, глубокий лесной зелёный как основной
брендовый цвет, золото — акцент премиальных тарифов. Заголовки — `Fraunces`,
текст — `Manrope`, денежные суммы — `IBM Plex Mono` с табличными цифрами:
сквозной мотив «цифры считаются на глазах» (анимированные счётчики баланса и
цены) как фирменный приём. Секция Dashboard Preview инвертирована в тёмный
фон — самый сильный визуальный акцент страницы.

## Известные ограничения

- `public/og-image.svg` используется как Open Graph превью в виде SVG — часть
  соцсетей (например, старые краулеры Facebook) ожидает растровый PNG/JPG;
  для прод-деплоя стоит сконвертировать его в PNG 1200×630.
- Кнопки «Войти» / соцссылки в футере ведут в никуда (`href="#"`) — это
  демонстрационный проект без бэкенда.
